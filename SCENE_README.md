# Wiggle Room

**Emote charades.** One player gets a secret prompt and acts it out using only their avatar's built-in emotes. Everyone else picks what it was. No typing, just vibes.

## How a round works

1. **Pick** — the player on stage chooses one of four prompts and steps onto the pink stage.
2. **Act** — they mime it with the emote wheel. Everyone else locks in an answer.
3. **Reveal** — the answer, who voted for what, and the points.

Guess early for a speed bonus. Several right in a row builds a streak multiplier. On stage you score for every player who reads you correctly, so being expressive pays better than being cryptic.

## Getting started

- **Two players start a match.** Eight rounds, then a fresh scoreboard.
- **Here first?** Tap *Play a round solo* to see how it works while you wait.
- **A different theme every day** — today's is shown in the lobby, tomorrow's at the end of the match.

Nothing to schedule, nobody to organise. Bring a friend — the game gets better the more people are reading each other.
